    一起核对四处内容

    新闻时间线、移植路线、工程档案和 社区公告。没有新证据时，保留原有内容。

    给 AI / 脚本的接口说明
    1. 用 GET /api/admin/content 读取 content，记下响应头 ETag。
    2. 在完整的 content 对象上修改，保留未编辑字段。向同一个地址发 PUT，请求体直接放这个对象，不包外层 content。
    3. 设置 Content-Type: application/json 和 If-Match（原样使用 ETag）。如果服务端配置了管理密码，还需 Authorization: Bearer <管理密码>。
    4. 遇到 412，重新读取最新内容，合并之后再用新 ETag 提交；不要直接重试旧稿。

    只编辑一个分区时，也可用 GET / PUT /api/admin/content/{section}（例如 news）。
