# 维护公开页面的三语内容

首页、关于、反馈、鸣谢和电脑配置预估支持简体中文、English 和日本語。启动 `node server.js` 或 `node preview.js` 后，在顶栏选择语言，也可直接访问 `/?lang=en` 或 `/?lang=ja`。浏览器会记住选择，公共站内链接和 RSS 链接会带上语言。简体中文是默认语言，也是缺失译文时逐字段使用的原文。

## 新增或删除界面文字

1. 在 HTML 保留简体中文默认值，在 `assets/i18n-pages.js` 用稳定的 `pages.<area>.<key>` 补齐 `[英文, 日文]`。纯文本使用 `data-i18n`。带图标或子节点的文案使用 `data-i18n-own` 或单独的文本元素。同步检查页面标题、描述、占位符和可访问名称。
2. 电脑配置预估页的专用文案（含动态结果、档位和储存标签）放在 `assets/i18n-hardware-check.js`。首页入口沿用 `assets/i18n-pages.js` 的共享词条。首页运行时文案放在 `assets/i18n-home.js`，反馈、弹幕和访问统计等控件文案放在 `assets/i18n-widgets.js`。删除入口或状态时，先检查是否仍有其他页面或脚本引用对应键。
3. 用三种语言走一遍入口和错误状态，检查 320px 窄屏与桌面上的换行、键盘焦点和菜单位置。运行 `node --test` 后重封并检查发布清单。

## 更改新闻、路线、档案或公告

在同一条记录上加可选的 `translations` 对象。控制台可通过原始 JSON 维护此字段。以下是虚构的新闻条目。

```json
{
  "id": "demo-news-example",
  "date": "2026-01-12",
  "title": "新增样例记录",
  "translations": {
    "en": { "title": "New example record" },
    "ja": { "title": "サンプル記録を追加" }
  }
}
```

按 `api/_content-locale.js` 中的字段表录入纯文本。记录 ID、仓库名、证据链接、日期、状态和评分输入共用原字段。更正原文时一起核对两种译文。删除记录时一起移除译文，并检查主页新闻选取、锚点和 RSS。发布前逐项检查新闻时间线、移植路线、工程档案和站公告。公开版样例及译文由 `fixtures/demo.js` 提供。

`GET /api/content?lang=en`、`GET /api/dashboard?lang=ja` 和 `GET /rss.xml?lang=ja` 按语言返回文案，并设置 `Content-Language`。内容接口按语言区分缓存，RSS 条目在各语言下共用同一身份。

## 弹幕历史的设备端翻译

在本地站点模式打开弹幕历史，然后选择「自动翻译」。支持相关 API 的浏览器可在安全上下文中使用该功能，首次使用时可能下载语言包。用户启用后，译文随原文显示在浏览器里。重新打开页面时默认关闭。只读演示提供示例数据和反馈说明。

身份标签只改变弹幕显示。站长可以在控制台的标签管理视图为账号授予额外的徽章；账号权限不会随徽章改变。弹幕历史保存发送时的徽章状态，之后撤销授权不重写已有记录。渲染徽章的英文和日文名称与弹窗选择项共用词条。
